---
title: Boundaries
description: What identity layers may own and what must stay in the product app.
---

Branding changes presentation. It does not change product authority.

## Identity may own

- logos and brand assets
- palette and semantic color roles
- CSS variables
- typography defaults
- Nuxt UI component defaults
- app shell presentation
- docs styling
- voice and public copy rules
- footer and legal presentation

## Identity must not own

- authorization
- tenant isolation
- domain rules
- data validation
- storage behavior
- billing, audit, or compliance behavior
- API, MCP, webhook, or job behavior
- production credentials

## Review question

Ask this before adding a branding change:

> If the brand changes, should the user still be able to do the same things with the same rules?

If the answer is no, the change belongs in the product app or domain package.
