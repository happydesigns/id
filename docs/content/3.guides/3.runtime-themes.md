---
title: Runtime Themes
description: Switch theme packs at runtime through CSS variables and Nuxt UI app config.
---

Runtime themes are plain serializable theme packs. Every shipped theme should include both `light` and `dark` CSS variables, because Nuxt UI applications commonly expose color-mode switching through `useColorMode()`.

```ts [app.config.ts]
import { defineBrandTheme } from '@happydesigns/id'

const clientTheme = defineBrandTheme({
  name: 'client',
  label: 'Client',
  semanticColors: {
    primary: 'blue',
    neutral: 'slate'
  },
  cssVariables: {
    light: {
      '--ui-bg': 'white',
      '--ui-text': '#334155',
      '--ui-text-highlighted': '#020617'
    },
    dark: {
      '--ui-bg': '#020617',
      '--ui-text': '#E2E8F0',
      '--ui-text-highlighted': 'white'
    }
  },
  ui: {
    button: {
      slots: {
        base: 'rounded-md font-medium'
      },
      defaultVariants: {
        color: 'primary',
        variant: 'solid',
        size: 'md'
      }
    },
    card: {
      slots: {
        root: 'rounded-lg shadow-none'
      }
    }
  }
})

export default defineAppConfig({
  id: {
    defaultTheme: clientTheme.name,
    themes: [clientTheme]
  }
})
```

## Switching

```vue [ThemeToggle.vue]
<script setup lang="ts">
const {
  themes,
  selectedName,
  setTheme
} = useBrandTheme()

const selectedTheme = computed({
  get: () => selectedName.value,
  set: value => setTheme(value)
})
</script>

<template>
  <USelect
    v-model="selectedTheme"
    :items="
      themes.map(theme => ({
        label: theme.label,
        value: theme.name
      }))
    "
    value-key="value"
    label-key="label"
  />
</template>
```

## Color mode

Use Nuxt's standard color-mode composable. `id` watches the document color-mode class and reapplies the selected theme's matching light or dark variables.

```vue [ColorModeButton.vue]
<script setup lang="ts">
const colorMode = useColorMode()
const isDark = computed(() => colorMode.value === 'dark')
</script>

<template>
  <UButton
    color="neutral"
    variant="ghost"
    :icon="isDark ? 'i-lucide-sun' : 'i-lucide-moon'"
    square
    @click="colorMode.preference = isDark ? 'light' : 'dark'"
  />
</template>
```

## Runtime-safe values

Use runtime themes for:

- CSS variables
- typography variables
- Nuxt UI semantic colors
- component slots and default variants that use shipped classes

Do not use runtime themes for:

- unbundled Vue components
- arbitrary remote CSS
- uncompiled Tailwind class names
- domain behavior
- credentials
