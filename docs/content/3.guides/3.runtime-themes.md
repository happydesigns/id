---
title: Runtime Themes
description: Switch theme packs at runtime through CSS variables and Nuxt UI app config.
---

Runtime themes are plain serializable theme packs.

```ts [app.config.ts]
import { defineBrandTheme } from '@happydesigns/id'

const clientTheme = defineBrandTheme({
  name: 'client',
  label: 'Client',
  semanticColors: {
    primary: 'blue',
    neutral: 'slate'
  },
  cssVariables: {
    light: {
      '--ui-bg': 'white',
      '--ui-text': 'var(--ui-color-slate-700)'
    },
    dark: {
      '--ui-bg': 'var(--ui-color-slate-950)',
      '--ui-text': 'var(--ui-color-slate-200)'
    }
  }
})

export default defineAppConfig({
  id: {
    defaultTheme: clientTheme.name,
    themes: [clientTheme]
  }
})
```

## Switching

```vue [ThemeToggle.vue]
<script setup lang="ts">
const {
  themes,
  currentName,
  setTheme
} = useBrandTheme()
</script>

<template>
  <USelect
    :items="
      themes.map(theme => ({
        label: theme.label,
        value: theme.name
      }))
    "
    :model-value="currentName"
    value-key="value"
    label-key="label"
    @update:model-value="
      value => {
        if (typeof value === 'string') {
          setTheme(value)
        }
      }
    "
  />
</template>
```

## Runtime-safe values

Use runtime themes for:

- CSS variables
- typography variables
- Nuxt UI semantic colors
- component default variants that use shipped classes

Do not use runtime themes for:

- unbundled Vue components
- arbitrary remote CSS
- uncompiled Tailwind class names
- domain behavior
- credentials
