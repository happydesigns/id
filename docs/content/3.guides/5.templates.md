title: Templates
description: Start a brand layer or themed app with giget templates.
---

`id` includes starter templates for the two common paths.

## Brand layer

Use this when the brand should become an importable Nuxt layer.

```bash [Terminal]
npx giget@latest gh:happydesigns/id/templates/brand-layer my-brand
cd my-brand
pnpm install
pnpm dev
```

The template contains:

- `brand.config.ts`
- `app/app.config.ts`
- `app/assets/css/brand.css`
- a starter logo component
- public favicon
- Nuxt layer export

## Themed app

Use this when the app owns its pages and only needs runtime theme packs.

```bash [Terminal]
npx giget@latest gh:happydesigns/id/templates/themed-app my-app
cd my-app
pnpm install
pnpm dev
```

The template contains:

- a Nuxt app extending `@happydesigns/id/nuxt`
- one local runtime theme
- a page using `useBrandTheme`
- standard Nuxt UI components

## Template rule

Templates are starting points. Keep durable identity rules in `brand.config.ts` and product behavior in the app that owns it.
