---

`id` includes starter templates for the main brand-layer path and a smaller direct-app path.

## Brand layer

Use this when the brand should become an importable Nuxt layer.

```bash [Terminal]
npx giget@latest gh:happydesigns/id/templates/brand-layer my-brand
cd my-brand
pnpm install
pnpm dev
```

The template contains:

- `brand.config.ts`
- `app/app.config.ts`
- `app/assets/css/brand.css`
- a starter logo component
- public favicon
- Nuxt layer export

## Direct themed app

Use this for prototypes or small apps that own their pages and want to use `@happydesigns/id` directly before extracting a separate brand layer.

```bash [Terminal]
npx giget@latest gh:happydesigns/id/templates/themed-app my-app
cd my-app
pnpm install
pnpm dev
```

The template contains:

- a Nuxt app extending `@happydesigns/id/nuxt`
- one local primary theme
- a page using `useBrandTheme`
- standard Nuxt UI components

## Template rule

Templates are starting points. Keep durable identity rules in `brand.config.ts` and product behavior in the app that owns it. For public reusable apps, prefer a neutral app plus an external brand layer.
