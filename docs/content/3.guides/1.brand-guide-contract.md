title: Brand Guide Contract
description: Define brand guides with typed metadata, palettes, tokens, assets, voice, component coverage, and usage rules.
---

Use `defineBrandIdentity` for the raw brand source object, then expose public guide metadata with `defineBrandGuide`.

```ts [brand.ts]
import { defineBrandGuide, defineBrandIdentity } from '@happydesigns/id'

export const brandIdentity = defineBrandIdentity({
  name: 'client-brand',
  packageName: '@client/brand',
  claim: 'The reusable identity guide for Client Brand.',
  logoAssetPaths: {
    crest: '/brand/crest.svg'
  }
})

export const brandGuide = defineBrandGuide({
  name: brandIdentity.name,
  packageName: brandIdentity.packageName,
  title: 'Client Brand',
  description: brandIdentity.claim,
  semanticColors: {
    primary: 'brand',
    neutral: 'slate'
  },
  usage: {
    useFor: ['Nuxt UI apps', 'Docus docs'],
    avoid: ['domain behavior', 'authorization']
  },
  assets: {
    logos: {
      crest: {
        name: 'Client crest',
        src: brandIdentity.logoAssetPaths.crest,
        role: 'crest',
        alt: 'Client Brand'
      }
    }
  }
})
```

## Recommended sections

For richer guide navigation, keep section metadata in the brand source file and map it into the public guide contract.

```ts [brand-sections.ts]
import { createGuideDocsSections, defineGuideSections } from '@happydesigns/id'

export const sections = defineGuideSections([
  {
    slug: 'colors',
    title: 'Colors',
    description: 'Palette, semantic roles, and usage guidance.',
    icon: 'i-lucide-palette',
    anchors: ['Palette', 'Semantic roles', 'Usage rules']
  }
])

export const docs = {
  sections: createGuideDocsSections(sections)
}
```

## Assets

`assets.logos` is a role map, not a fixed logo model. Use common roles like `logo`, `wordmark`, `symbol`, `mark`, or `appIcon` when they fit the brand, but custom roles such as `crest`, `seal`, `signature`, or `partner-lockup` are equally valid.

The shipped `IdLogo` component can render any configured role through `role="crest"`. If a brand needs richer logic, such as responsive lockups or complex light/dark switching, the brand layer should provide its own logo component.

## Validation

The helpers validate identity and guide data immediately. Invalid names, empty required strings, and malformed URLs fail at the boundary.

Use this failure early. A brand guide should be predictable before it becomes a layer.
