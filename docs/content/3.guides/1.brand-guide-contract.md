---
title: Brand Guide Contract
description: Define brand guides with typed metadata, palettes, tokens, assets, voice, component coverage, and usage rules.
---

Use `defineBrandGuide` for the durable identity source of truth.

```ts [brand.config.ts]
import { defineBrandGuide } from '@happydesigns/id'

export const brandGuide = defineBrandGuide({
  name: 'client-brand',
  packageName: '@client/brand',
  title: 'Client Brand',
  description: 'The reusable identity guide for Client Brand.',
  semanticColors: {
    primary: 'brand',
    neutral: 'slate'
  },
  usage: {
    useFor: ['Nuxt UI apps', 'Docus docs'],
    avoid: ['domain behavior', 'authorization']
  }
})
```

## Validation

The helper validates the guide immediately. Invalid names, empty required strings, and malformed URLs fail at the boundary.

Use this failure early. A brand guide should be predictable before it becomes a layer.
