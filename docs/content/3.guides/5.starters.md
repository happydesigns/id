`id` includes starters for the main brand-layer path and a smaller direct-app path.

## Brand layer

Use this when the brand should become an importable Nuxt layer.

```bash [Terminal]
npx giget@latest gh:happydesigns/id/templates/brand-layer my-brand
cd my-brand
pnpm install
pnpm verify
pnpm dev
```

The same template can be passed through Nuxt's CLI:

```bash [Terminal]
pnpm create nuxt@latest my-brand --template gh:happydesigns/id/templates/brand-layer
```

The starter contains:

- `brand.ts`
- `app/app.config.ts`
- `app/assets/css/brand.css`
- a reusable logo component in the public layer
- public favicon
- a public Nuxt layer export at the repository root
- a separate Docus reference app in `docs/`

`brand.ts` owns the reusable neutral definition, including structured runtime assets with accessible labels and light/dark media hints. `app/app.config.ts` exposes those assets and maps the same definition to Nuxt UI, while the starter logo component renders them through `IdLogo`. The Docus app extends the root layer plus `@happydesigns/id/guide` and adds the optional guide contract. Its helpers, pages, and prose are not shipped to consuming apps.

## Direct themed app

Use this for prototypes or small apps that own their pages and want to use `@happydesigns/id` directly before extracting a separate brand layer.

```bash [Terminal]
npx giget@latest gh:happydesigns/id/templates/themed-app my-app
cd my-app
pnpm install
pnpm verify
pnpm dev
```

The starter contains:

- a Nuxt app extending `@happydesigns/id/nuxt`
- the standard Nuxt UI `UApp` root in `app/app.vue`
- one local primary theme
- a page using `useBrandTheme`
- standard Nuxt UI components

## Starter rule

Starters are project scaffolds, not brand doctrine. Keep durable identity rules in `brand.ts` and product behavior in the app that owns it. For public reusable apps, prefer a neutral app plus an external brand layer.

The repository test suite includes starter smoke checks for both boundaries: the root remains Docus-free and consumer-safe, while `docs/` resolves the root layer, guide app config, and inherited global components.
