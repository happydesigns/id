---
title: Start a project
description: Export a native Nuxt UI brand with an optional documentation host.
---

Open [Brand Studio](/studio), select or create a brand, then choose **Export → New project**. The export contains a native Nuxt UI layer, its editable source and a minimal Studio playground.

```bash
pnpm install
pnpm dev
```

Select **Include Docus guide** when the project needs documentation. Applications consume the native brand layer without Studio or Docus.

For unpublished ID versions, install a reviewed package archive as described in the [Studio guide](/guides/brand-studio).

## Repository examples

The directories under `templates/brand-layer` and `templates/themed-app` are workspace integration examples. They depend on the repository pnpm catalog and are not standalone Giget starters or published package contents. Use Studio export for an independent project.
