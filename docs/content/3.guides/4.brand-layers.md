title: Brand Layers
description: Build full Nuxt brand layers with @happydesigns/id contracts and Nuxt UI defaults.
---

A brand layer is the right shape when branding owns more than runtime-safe values.

## Minimal layer

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  extends: ['@happydesigns/id/nuxt'],
  css: ['~/assets/css/brand.css'],
  app: {
    head: {
      link: [
        { rel: 'icon', type: 'image/svg+xml', href: '/favicon.svg' }
      ]
    }
  }
})
```

## App config

```ts [app.config.ts]
import { brandGuide, brandTheme } from '../brand.config'
import { createNuxtUiAppConfig } from '@happydesigns/id'

const nuxtUiConfig = createNuxtUiAppConfig(brandTheme)

export default defineAppConfig({
  id: {
    name: brandTheme.name,
    theme: brandTheme,
    guide: brandGuide
  },
  ui: nuxtUiConfig.ui
})
```

Nuxt does not require `id.theme`. `id` uses it as the typed source for validation, generated CSS variables, playground previews, runtime-safe theme switching, and Nuxt UI app-config derivation.

## Layer ownership

Brand layers can provide:

- public assets
- metadata
- CSS token definitions
- Nuxt UI defaults
- logo components
- app shell wrappers
- docs styling

They should not provide product permissions, storage behavior, API contracts, or workflow rules.

## Multi-brand deployments

For deploy-time brand selection, keep the app brand-neutral and select the layer in `nuxt.config.ts`.

```ts [nuxt.config.ts]
const brandLayer = process.env.NUXT_BRAND_LAYER ?? '@client/default-brand'

export default defineNuxtConfig({
  extends: [brandLayer]
})
```

This keeps one app source while allowing deployment-specific brand expression.

For development against an unpublished brand layer, clone or download the layer into `layers/90.brand` and run the app normally.

```bash [Terminal]
npx giget github:client/brand layers/90.brand
pnpm dev
```

`90.brand` is a convention, not a Nuxt requirement. It makes the layer order obvious in projects that rely on Nuxt's auto-scanned `layers/` directory. If an app already has late override layers, choose a name that keeps the brand after base layers and before intentional local overrides.
