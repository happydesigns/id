## Semantic colors

```ts [app/app.config.ts]
export default defineAppConfig({
  ui: {
    colors: { primary: 'blue', neutral: 'zinc' }
  }
})
```

## Choose the right scope

| Change | Where it belongs |
| --- | --- |
| Shared brand colors | Brand layer |
| Product-specific defaults | Application configuration |
| A single button variant | Component props |

## Review both modes

Check text, forms and navigation in light and dark mode before applying changes.
