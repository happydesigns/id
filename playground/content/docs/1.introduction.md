## Start with your brand

Use the same colors, typography and assets in your product, documentation and learning experience. Each application keeps its own content and behavior.

::note
This documentation uses Docus itself, including navigation, search and Markdown components.
::

## Add a brand layer

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  extends: ['@example/brand']
})
```

## Build on Nuxt UI

Use semantic colors and the standard component defaults. A brand layer changes their appearance while their interaction stays familiar.
