---
title: Installation
description: Add the shared brand to a Nuxt application.
---

## Install the package

```bash [Terminal]
pnpm add @example/brand
```

## Extend the layer

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  extends: ['@example/brand']
})
```

## Use the components

```vue [app.vue]
<template>
  <UApp>
    <UButton>Invite your team</UButton>
  </UApp>
</template>
```

The layer provides the appearance. Nuxt UI handles focus, keyboard interactions and component states.
