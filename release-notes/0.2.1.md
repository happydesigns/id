## Highlights

- Switching brands restores component defaults correctly instead of retaining styles from the previous brand.
- Studio profiles can also style the documentation, and the landing page demonstrates shared branding across applications.
- Native brand exports include a standalone Studio; the optional Docus guide has its own working landing and documentation routes.
- Package entrypoints, source writes, generated projects and release artifacts receive broader automated verification.

## Upgrade notes

Existing public entrypoints and version-1 Studio documents remain supported. Replace the pinned ID archive and update the lockfile; regenerate native output after upgrading the authoring package. Applications consuming native brand layers still need neither ID nor Docus at runtime.

Workspace example projects are no longer bundled into the package. Use Studio's New project export to scaffold a brand; repository examples remain available in source.

Node support follows Nuxt's supported release lines. Tailwind CSS retains its existing v4 peer range; the lockfile records the tested dependency versions.
