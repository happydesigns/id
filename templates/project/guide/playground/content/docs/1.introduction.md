## Install

Extend the brand layer and register your application CSS entry.

```ts [nuxt.config.ts]
export default defineNuxtConfig({ extends: ["{{packageName}}"], css: ['~/assets/css/main.css'] })
```

```css [app/assets/css/main.css]
@import "tailwindcss";
@import "@nuxt/ui";
@import "{{packageName}}/styles.css";
```

Docus hosts already own the framework entry: import only the brand stylesheet in app/app.css, as this playground does.

## Customize

Use Studio to review changes to the shared source. Your application keeps its own pages and behavior.
