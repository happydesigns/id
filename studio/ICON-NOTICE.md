# Nuxt UI icon mappings

icon-sets.ts and icon-defaults.ts are adapted from Nuxt UI (MIT):
https://github.com/nuxt/ui/blob/v4/docs/app/utils/theme/icons.ts
https://github.com/nuxt/ui/blob/v4/src/theme/icons.ts

The upstream license is preserved in app/components/playground/LICENSE.md.
The Studio stores standard mappings as theme.ui.icons; supplemental example icons
use the upstream per-pack overrides and Lucide fallback. Other Iconify collections
resolve through Nuxt Icon's API fallback, as in Nuxt UI Theme Studio. Consumers may
bundle their selected collection locally for offline use.
